Ramas en Git:
trabajar en equipo sin pisarnos

🌿
Una rama es una copia paralela del proyecto: cada uno trabaja en la suya sin romper lo de los demás.

🎬 Así trabaja un equipo con ramas

🚀 main = el código estable que todos comparten
1

🌱Crear rama

git switch -c
feature/login
-c = create
(crear)
2

💾Guardar

git commit -m
"feat: login"
-m = message
(mensaje)
3

☁️Subir

git push -u
origin
feature/login
-u = upstream
(enlazar)
4

🔍Pull Request

El equipo revisa + tests automáticos

5

🔀Merge

Tu rama se une a la principal

6

🧹Limpiar

git branch -d
feature/login
-d = delete
(borrar)
🔒main protegida: nadie sube directo
⏱️Ramas cortas: de 1 a 3 días
🔄Sincroniza tu rama cada día
⚡¿Conflicto? Elige qué código queda
